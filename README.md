# MS-LSFTrack Release Package

This package contains the public code and released results for MS-LSFTrack.

```text
MS-LSFTrack-GitHub-Release-20260717/
├── code/
│   └── MS-LSFTrack/
└── results/
    └── MS-LSFTrack-results/
```

## Code

`code/MS-LSFTrack` is the GitHub repository directory. It contains:

- source code,
- dataset and experiment configs,
- training, tracking and evaluation scripts,
- public ReID weight for BoxMOT baselines,
- reproduction documentation.

## Results

`results/MS-LSFTrack-results` contains:

- released MS-LSFTrack checkpoints,
- final tracking outputs,
- evaluation summaries,
- comparison and ablation tables,
- configs used to produce the released results.

The dataset files are not included. Prepare datasets using the clean layout described in `code/MS-LSFTrack/DATASET_FORMAT.md`.
